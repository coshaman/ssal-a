# Block Complexity Certificate

The machine-readable certificate is `complexity_certificate/blockwise_sample.json`. It was generated by `python -m complexity_certificate.generate` for `n=8`, `omega=8`, modulus `998244353`.

Expected invariant evidence: 406 distinct block creations and 722 later cache hits. Every hit uses an existing `(t,x,z,ell,omega)` vector; truncation is `K=n-x-ell`; and the cache is cleared by `configure` and `choose_init`, so it is scoped to one `(n,p,omega)` run.

This certificate checks the implementation invariant in `research/FULL_DEPENDENCY_PROOF.md`; the asymptotic proof is in `research/GLOBAL_COMPLEXITY_PROOF.md`.
