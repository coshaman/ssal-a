                                                                                        Abstract
                                                 We compute the number of unlabeled chordal graphs on n vertices, both the total count
                                             (OEIS A048193) and the connected count (OEIS A048192), extending two sequences whose
                                             published values had remained at n = 15. The method is a Pólya–Burnside enumeration: the
                                             number of unlabeled graphs in a class closed under relabeling is the average over Sn of the
                                             number of labeled graphs fixed by each permutation. The technical core is the evaluation, for
                                             an arbitrary permutation π, of the number of π-invariant labeled chordal graphs. We give a
                                             dynamic program for this quantity that lifts the evaporation-based labeled chordal counting
                                             of Hébert-Johnson, Lokshtanov and Vigoda to the equivariant setting. Its central structural
                                             ingredient is a divisor-bundle decomposition: when a connected piece spans a cyclic orbit of size
                                             c, it forms, for each divisor d | c, a d-fold bundle whose constituent is an object of the same
                                             kind in the cyclic world of order c/d, computed by the same program recursively. We prove
                                             the decomposition and the correctness of the resulting recurrences,
                                                                                                      √           and we prove that the full
                                             Burnside computation runs in sub-exponential time nO( n) . We report the new terms through
                                             n = 20 and describe four independent validations, including exact agreement with all previously
                                             known values of both sequences and an Euler-transform consistency check.


                                        1    Introduction
                                        A graph is chordal if it has no induced cycle of length at least four. Chordal graphs are a central
                                        class in algorithmic graph theory, characterized by perfect elimination orderings and by tree de-
                                        compositions whose width equals the clique number minus one. Two integer sequences count them
                                        up to isomorphism:
                                                             A048193(n) = #{chordal graphs on n nodes},
                                                             A048192(n) = #{connected chordal graphs on n nodes},
                                        both up to isomorphism. Their published data extended only to n = 15.
                                            For the labeled count, Hébert-Johnson, Lokshtanov and Vigoda [1] gave a polynomial-time
                                        dynamic program based on an evaporation process that repeatedly deletes all simplicial vertices.
                                        Counting graphs up to isomorphism, however, is governed by Burnside’s lemma and requires count-
                                        ing labeled chordal graphs invariant under each permutation of the vertices. Hébert-Johnson and
                                        Lokshtanov [2] proved that counting labeled chordal graphs with a prescribed automorphism is
                                        fixed-parameter tractable in the number of moved points µ, with a running time of O(27µ n9 ); in
                                        the regime relevant to the Burnside sum, where µ may be as large as n, that bound is single-
                                        exponential in n, and no exact unlabeled enumeration was carried out there.

= ord(π). The orbits of π partition V ; an orbit of size c is a c-cycle, on which π acts as a single
cycle. A part of size c in λ is such an orbit.

2.2    Evaporation
Definition 1 (Evaporation with an exception clique; [1]). A vertex v of a graph G is simplicial
if its neighborhood NG (v) is a clique. Given a clique X ⊆ V (G), set G0 = G and, for t ≥ 1, let
Lt be the set of simplicial vertices of Gt−1 not in X and put Gt = Gt−1 \ Lt . For chordal G this
terminates with V (Gt ) = X; the sequence L1 , . . . , LT is the evaporation of G with exception X, G
evaporates at time T , the evaporation time of v ∈ / X is the index t with v ∈ Lt , and LG (X) := LT
is the last layer.
    We write τ (v) for the evaporation time of v.


3     The orbit-level process and its structure
We run the evaporation process on a π-invariant chordal graph with a π-invariant exception clique.
The following lemma is what makes an equivariant dynamic program well-defined: the process acts

Lemma 1 (Orbit-evaporation). Let G be chordal with π ∈ Aut(G), and let the exception clique X
be π-invariant. Then π(Lt ) = Lt and π ∈ Aut(Gt ) for every t. Consequently τ is constant on each
π-orbit: every orbit evaporates in a single layer.

Proof. For any π-invariant graph H one has NH (πv) = π(NH (v)), and π maps cliques to cliques;
hence v is simplicial in H iff πv is. We induct on t. Base: G0 = G is π-invariant. Step: if
π ∈ Aut(Gt−1 ) then simpliciality in Gt−1 is π-stable and X is π-invariant, so π(Lt ) = Lt ; deleting
the π-invariant set Lt leaves π an adjacency-preserving bijection of V (Gt ), i.e. π ∈ Aut(Gt ). Since
π(Lt ) = Lt , each π-orbit is contained in or disjoint from Lt , so τ is constant on orbits.

    A connected component need not be π-invariant; rather π permutes the components. The orbit
of a component is a bundle.

with π-orbit B = {K, πK, . . . , π d−1 K} of size d. Then:
  (i) d | N and Stab(K) = ⟨π d ⟩, so K is π d -invariant;

Proof. ⟨π⟩ is cyclic of order N . By orbit–stabilizer [⟨π⟩ : Stab(K)] = d, so | Stab(K)| = N/d and

Lemma 3 (Block decomposition). Let O be a π-orbit of size s and H = ⟨π d ⟩ for d | N . Then
H acts on O with exactly gcd(d, s) orbits ( blocks), each of size s/ gcd(d, s). Any π d -invariant set
meets O in a union of whole blocks.

Proof. Identify O ∼= Z/sZ with π|O translation by 1, so π d |O is translation by d. The orbits of
⟨d⟩ ≤ Z/sZ are the cosets of the subgroup generated by d, which has order s/ gcd(d, s); there are
gcd(d, s) of them. A π d -invariant set is a union of such orbits.

Lemma 4 (Recursive sub-world). With K, B, d as in Lemma 2, the component K is a connected
chordal graph invariant under the cyclic group H = ⟨π d ⟩ of order N/d. Every π-orbit O of size s
that K meets contributes to K a union of blocks of size s/ gcd(d, s). Moreover, if O has size c with
d | c and is one of the orbits spanned by B, then K meets O in exactly one block, a single H-orbit
of size c/d. Hence K is an object of the same type on a strictly smaller cycle type, and the bundle
structure recurses, terminating at d = N in the labeled world.

Proof. K is H-invariant (Lemma 2(i)) and H is cyclic, so by Lemma 3 K ∩ O is a union of blocks of
size s/ gcd(d, s). For a spanned O with d | c we have gcd(d, c) = d, so O has exactly dSblocks, each
of size c/d. The bundle has period d, so its d components are distinct and partition j π j K ⊇ O.
As K ∩ O ̸= ∅ and πO = O, each translate meets O in π j (K ∩ O) ̸= ∅; these d sets are pairwise
disjoint and cover O, and π j is a bijection, so d |K ∩ O| = |O| = c and |K ∩ O| = c/d. Since K ∩ O
is a union of size-(c/d) blocks of total size c/d, it is exactly one block. The spanned orbit of size c
thus becomes a sub-orbit of size c/d < c (as d > 1), so the recursion is well-founded and ends when
d = N , where H = {id} and K is an unconstrained labeled graph.

The recurrences of Section 5 and the Burnside sum (1) were implemented and evaluated exactly in
rational arithmetic. Table 1 lists both sequences; the entries for n ≤ 15 reproduce the previously
published values, and n = 16 through 20 are new (n = 16–18 have been submitted to the OEIS;

    We stress that extending these sequences is not a matter of generating one more graph. The
Burnside sum (1) requires the exact value of fix(λ) for every cycle type λ ⊢ n, and the number of
cycle types is the partition number p(n), which grows sub-exponentially (p(15) = 176, p(20) = 627).
The difficulty is concentrated in the cycle types with many small orbits, where direct enumeration
is hopeless and the equivariant recurrences of Section 5 are essential; it is computing all of these
fix(λ), not enumerating graphs, that had kept the sequences at n = 15.

8    Conclusion
We have given a concrete equivariant dynamic program for counting permutation-invariant chordal
graphs, built on the labeled evaporation program of [1]. Its correctness rests on a divisor-bundle
decomposition (Theorem 1) that reduces each equivariant recurrence to its labeled counterpart, and
the full Burnside computation runs in sub-exponential time (Theorem 4). The resulting enumer-
ation extends the unlabeled chordal sequences A048192 and A048193 past their previous frontier.
The orbit-bundle lifting strategy may be adaptable to other graph classes that admit a compatible
labeled decomposition recurrence; we leave such extensions to future work.
